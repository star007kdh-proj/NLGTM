## Purpose
Predict the target of taken indirect branches (not returns) for the BPU, using PC and folded path history tagged tables, and learn from resolved branches; a hit overrides the BTB target. [Ittage.scala:19-21 (Seznec ITTAGE), Ittage.scala:264-265, Doc:27-33, bpu/Bundles.scala:61 `needIttage = isIndirect && !hasPop`]

## Mechanisms
- M1 s1_fire && enable → every table gets req{startPc, foldedHist}; bank/set/tag hashed; SRAM read on the selected bank only   [Ittage.scala:190-194 → IttageTable.scala:121-127, 153-156]
- M2 registered read data valid && tag match → resp{cnt, usefulCnt, targetOffset} valid   [IttageTable.scala:129-131 → 158-166]
- M3 S2: table resps → provider = longest-history hit, altProvider = next longest   [Ittage.scala:205-216 → 217-223]
- M4 S2: each resp pointer → region table read; region = (hit && !usePcRegion) ? stored region : PC region   [Ittage.scala:225-229 → RegionWays.scala:64-68, Ittage.scala:232-239]
- M5 S2/S3: provider target unless provider cnt saturate-negative and alt hit → alt target; prediction.hit = s3_fire && provided   [Ittage.scala:249-255 → 264-265]
- M6 S2: allocatable = tables missing && useful saturate-negative && longer than provider; LFSR pick, else first → meta.allocate   [Ittage.scala:296-301 → 302-303]
- M7 t0_fire → latch train, foldedPhr, meta; provider/alt/allocate bits latched only when their valid is set; altProviderTarget only when provider cnt saturate-negative   [Ittage.scala:116-124 → 130-153]
- M8 train branch = first slot with valid && needIttage && taken (assert at most one) → updateValid = found && RegNext(t0_fire); mispred taken from the train bundle   [Ittage.scala:156-164 → 167, 187]
- M9 updateValid && provider valid → provider entry: cnt +/- by (providerTarget == real target); useful := altDiffers ? (correct) : keep; target overwritten only when alloc or old cnt saturate-negative   [Ittage.scala:348-360 → IttageTable.scala:243-259]
- M10 updateValid && provider valid && alt was used && mispred → alt entry cnt decremented; its useful and target untouched   [Ittage.scala:335-346 → IttageTable.scala:190-194, 243-247]
- M11 updateValid && mispred && !(provider correct && provider unconfident) && allocate valid → allocate table gets new entry: valid, fresh tag, cnt WeakPositive, useful 0, real target   [Ittage.scala:378-387 → IttageTable.scala:242-259]
- M12 same gate as M11 → tickCnt +1 when no allocatable slot, -1 when allocation happened   [Ittage.scala:379 → bpu/SaturateCounter.scala:63-65, 108-109]
- M13 tickCnt saturate-positive → tickCnt := 0, one-cycle reset pulse → next cycle every table sets needReset   [Ittage.scala:395-398 → 402 → IttageTable.scala:185-186]
- M14 needReset && !(req.fire || update.valid) → one set per cycle: useful-only bitmask write (useful := 0) at resetSet pushed to every bank's write buffer; after setsPerBank such cycles needReset cleared   [IttageTable.scala:182-184 → 190-194, 210-216, 249-253; 184 → 187-188]

- M17 allocation && real target region != PC region → region table write: reuse matching region, else free slot, else PLRU victim; pointer stored in the new entry; else usePcRegion := 1 and no region write   [Ittage.scala:312-319 → RegionWays.scala:54-58, 82-90]

- M19 power-on: SRAM banks self-reset; req.ready := !powerOnResetState until all banks first ready; resetDone hardwired true   [IttageTable.scala:142, 230-239; Ittage.scala:56]

## Open questions
- M14 advances only in cycles with neither a predict read nor an update; no bound on sweep completion is stated in code (doc calls it a structural limit)   [IttageTable.scala:182, Doc:285]
- M12 decrements the tick on a successful allocation; the doc describes only the increment   [Ittage.scala:379, Doc:268]
- M15 pushes an update with valid regardless of write-buffer ready; a full buffer evicts a pending write (counted as drop, never prevented)   [IttageTable.scala:212, 276; bpu/WriteBuffer.scala:150-166]
- M14 sweep write and M15 update write to the same set land in one write buffer; a same-set hit replaces the pending entry's data and bitmask (external behaviour)   [IttageTable.scala:212-215, bpu/WriteBuffer.scala:93-100, 172-186]
- M6 decides the allocation slot from useful bits read at predict time; M11 writes it at train time without re-checking the current useful bit   [Ittage.scala:296-303, 380-387]
- M17 PLRU replacement overwrites a region that stored entries may still point to; nothing invalidates them   [RegionWays.scala:82-87, Doc:362-369]
- M18 forces usePcRegion := 1 when the meta target region is no longer in the region table; the comment says this "requires further consideration"   [Ittage.scala:313-315, 327, 331]
- M21 useAltOnNa is dead state   [Ittage.scala:76]
- s1_isIndirect is hardwired true, so ittage_closed_due_to_uftb_info can never count   [Ittage.scala:85, 418]
- resetDone is hardwired true while table SRAMs self-reset and gate req.ready   [Ittage.scala:56, IttageTable.scala:239]
